# Интервью мастеров

Текст хранится в `<slug>.json`, подготовленные изображения — в `<slug>.media.json`. Каталог автоматически подключается к окнам мастеров и отдельным страницам `/masters/<slug>/`; новые шаблоны и маршруты для каждого человека создавать не требуется.

1. Сохранить переданный текст и оригиналы в `artifacts/master-articles/<slug>/`. В `media-sources.json` перечислить изображения с уникальными id, локальным путём, точным SHA-256 и описанием сцены. Оригиналы не перезаписывать.
2. Создать JSON по примеру `sofya-shalaginova.json`: уникальный slug, точный masterId из `content/team.json`, заголовок, описание, обложка, ссылка и хеш исходного текста. В sections разместить блоки qa (вопрос, абзацы ответа, строка исходника) и photos (id изображений, подпись). Вступление раздела допускается в intro. Заключение хранится в closing. Слова мастера сверять с исходником, не дополнять выдуманными фактами.
3. Выполнить `python scripts/prepare-master-article-images.py <slug>`. Генератор проверяет хеши использованных оригиналов, экспортирует только упомянутые снимки, не увеличивает их и создаёт `<slug>.media.json` с описаниями, размерами и хешами файлов.
4. Проверить `node node_modules/astro/astro.js check`, затем `node node_modules/astro/astro.js build` и `node --test tests/*.test.mjs`. Отдельно сверить полноту нового текста и проверить статью, окно мастера и персональную запись на широком и узком экране в обеих темах.

MasterStory владеет структурой статьи, уровнями заголовков, галереями, responsive-изображениями и ленивой загрузкой. Окно и отдельная страница используют одни данные. Имя и персональная ссылка записи берутся из team.json. Дата публикации автоматически не выдумывается; локальный noindex сохраняется.

15.11.2026 по прямым ссылкам владельца добавлены Милена/Соня/Светлана/Любовь:71вопрос,63фото, все14каруселей. Исходный публичный DOM сохраняется как `source-dom.json`; `data-sizes` содержит каждый кадр и его наибольший доступный размер. Импорт `python -X utf8 scripts/import-vk-interviews.py --install` проверяет автора/размеры/хеши, сохраняет исходный порядок всех текстов и сначала готовит изображения во временной папке. Media-каталог появляется в live-glob раньше самой статьи, чтобы HMR не показывал незавершённую запись. Старые оригиналы при смене фотографии сохраняются с отдельным хешированным именем.

Новые статьи не получают придуманных глав. Пустой title раздела означает один поток вопросов H2 на странице/H3 в окне. `lead` и `coverCaption` сохраняют исходное вступление/подпись обложки; блок `text` сохраняет промежуточный текст, исходный подзаголовок или продолжение цитаты (`quoted:true`). Элемент с `heading:true` использует роль вопроса Manrope600, а не декоративный надзаголовок. Полноту/порядок/все кадры независимо сверяет `vk-interviews.test.mjs`; браузерный набор — `iteration62-interviews.py`.
