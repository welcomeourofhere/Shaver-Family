# Header: перенос записи и растяжение капсулы

16 ноября 2026. Статус Header: READY / source freeze; compiled gate чистого production-кандидата `5d36176754bbdd000991` пройден. Изменены только `Header.astro`, `header.css` и проверка этого компонента. Footer, Works, API и общие токены размеров в этой задаче не менялись.

## Воспроизведённая причина

Шапка использовала симметричную сетку `1fr / 96px / 1fr`. Правой группе нужно около 439 CSS px: часы, телефон, запись и два промежутка. Часы появлялись уже после 1000 px ширины контейнера, когда правая колонка ещё имела только 428–439 px. `flex-wrap:wrap` переносил запись на второй ряд. Высота капсулы росла с 64 до 122 CSS px.

Точный локальный диапазон воспроизведения: viewport 1039–1061 CSS px. Публичные и локальные значения шрифтов и полей совпали: метаданные 13 px, запись 16 px, прежние поля 12/24 px. Перенос не вызван изменением Select CSS. Для сравнения сохранены исходники и снимок в `artifacts/iteration66/header-regression/baseline/`.

Увеличение масштаба и состояние floating объясняют видимую высоту на скриншоте владельца: `122 × 1,25 × 1,03 ≈ 157 px`. Это сопоставление с пиксельным размером скриншота, а не утверждение о настройке браузера владельца. Для визуального сравнения получены кадры в том же CSS-диапазоне с raster scale 1,25.

## Исправление владельца компоновки

Обе группы Header сохраняют одну строку. Часы и второстепенный пункт переходят в компактное состояние одновременно на границе `80em`: при обычной роли 13 px это 1040 px контейнера, с запасом до проблемного диапазона. Контейнер получает размер шрифта из существующего `--header-meta-font`, поэтому границы реагируют и на увеличение текста.

При крупном тексте телефон становится существующей иконкой из `ContactGlyph` с полным доступным именем и номером. «Подарки» переходят в «Ещё»; если тесно и главному пункту, используется предусмотренная общим источником подпись «Цены» с полным `aria-label`. «Онлайн-запись» сохраняет полный текст, шрифт и поля. В штатном размере «Подарки» остаются до мобильного режима, а «Работы» доступны в главной строке или «Ещё».

Пункты теперь выбираются по ID, а не по позиции `slice` в общей навигации. Добавление «Работ» ранее сдвигало позиционную роль «Подарков». В каждом состоянии суммарно доступны десять уникальных направлений без дубликатов и пропавших ссылок.

Начальная компоновка готова в HTML/CSS, без измерений и перестановки после загрузки. Общие владельцы popup, движения, фокуса и записи сохранены. Код `header-menus.ts` и физика анимации не менялись.
