# Tilda host canvas — iteration65D

The actual published C audit found a platform-boundary defect: the site's dark root canvas was covered by opaque light Tilda backgrounds on `body.t-body` and `#allrecords.t-records`. The prior C native fixture intentionally contained no Tilda background, so its passing theme cases did not exercise this platform setting. The C publication remains a historical fact; it is not final visual acceptance of this defect.

The correction belongs to the existing exporter `HOST_CSS`: make both host backgrounds transparent, leaving the site's root `--surface` as the single canvas-colour owner. The client CSS/JavaScript must remain unchanged. The fixture helper now accepts `--host-background '#RRGGBB'`, applies a normal opaque inline colour to both native wrappers, and records the classes/colour in its provenance. A normal inline colour faithfully challenges the export boundary; no old C fixture or test artifact is edited.

The focused regression is `tests/iteration65-host-canvas.py --origin URL --engine chromium|firefox|webkit --label NEWLABEL`. It activates the renderer before observing widths390/961/1440 and both themes, checks the root colour against its actual `--surface`, requires transparent body/record wrappers, and samples a visible canvas pixel. It captures body gap, contacts and footer and checks horizontal overflow. No stylesheet is injected, no network response is intercepted, and no booking is submitted. Existing output labels are rejected rather than overwritten.

The only production change for E extends the **same** exporter rule to `body.t-body,#allrecords,#t-header,#t-footer{background:transparent!important}`. No client CSS/JavaScript, component layout, source content or secondary project-HEAD patch was introduced. The fixture's opaque-host mode now models the actual generic `.t-records` background as well as the previous body/allrecords inline colours. The browser harness checks all four native wrappers plus three footer edge/corner pixels. Targeted Python contracts check the complete selector group and the stronger native host model.
