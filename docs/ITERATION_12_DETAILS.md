# Двенадцать уточнений: команда, контакты, hero, услуги, подарки

04.11.2026. Локальные изменения. Публикация, CRM и отправка сообщений не входят в задачу.

1. Отзывы и увлечения — факты владельца из текущего сообщения; исходные имена/портреты/стаж учебного набора сохраняются. Подсчёты датированы отдельно.
2. Общий контактный диалог: Telegram, MAX, ВКонтакте, телефон. SVG берутся из действующего sprite SHAVER FAMILY. Телефон в шапке открывает этот диалог. MAX — явно разрешённая владельцем заглушка до предоставления URL. Telegram — официальный формат ссылки по рабочему номеру; VK — найденная группа soyuz_kirov.
3. Крайний левый пункт шапки получает pill-radius через параметр общего состояния, без дополнительного hover-правила.
4. Планшетный cashback растягивается по высоте соседнего купона. Рисунок/лучи используют одинаковую реальную высоту; слой флагштока рисуется над фотографией. Пульт фото отступает влево в той же компоновке.
5. Название услуги крупнее описания на четверть базового модуля; время имеет меньшую непрозрачность. Категория при hover получает собственный фиксированный цвет.
6. Подарки: только red/yellow/ink/blue, без одинаковых ортогональных соседей; SVG меньше на30% относительно предыдущей величины1/φ.
7. Сертификат: сцена → заголовок → описание → покупка. Карты больше и смещены вверх; разрешённый overhang учитывается геометрией сцены и не меняет высоту блока во время взаимодействия. Нижний край синего блока по-прежнему выровнен с подарками.
8. Размерные формулы остаются в design.ts/design.json: модуль4px, φ, адаптивные ограничения. Состояния кнопок — общие action/icon роли; параметры компонентов задаются у владельца.
9. Проверки: check/build, Node, реальные viewport320–1920, данные6мастеров, цветовые соседства, клавиатура/закрытие контактного окна, размеры подписей, перекрытие флага/пульта, новая разрешённая геометрия сертификатов и стабильность следующего раздела.

Применяются Ponytail full, ui-ux-design-system, agent-browser и verification-before-completion. Принятый дизайн индикатора не меняется.
