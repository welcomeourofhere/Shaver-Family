# Уточнения главной страницы — 05.11.2026

1. Акции: фиксированный цвет поверхности; раздельные масштабы активного и наведённого фото складываются. Общие sound/haptic-настройки сохраняются. «Акция: / Отец и сын» в двух строках; день рождения ±7 дней.
2. About: нативный CSS sticky заголовка; его ограничитель заканчивается синхронно с последним слоем. Убрать scroll-обработчик перемещения текста.
3. Типографика: адаптировать bindRuns из shared/typography.js Shaver Family, сохранять inline-разметку, исключать редактируемый/технический текст, поддерживать динамический контент. Сохранить Molot/Manrope и шкалу ролей. Заменить неполный Molot.woff2 полной версией из брендбука с родным знаком процента. Общее выделение текста в брендовой палитре.
4. Сертификаты: четыре предмета в ряд (лицо + обороты 1000/2000/3000), немного крупнее. Сохранить scroll/pointer/keyboard/click; выбранный предмет становится верхним, touch targets и границы сцены проверяются на узких экранах.
5. Hero: лозунг над всей композицией в3строки, внутри фото —10актуальных публикаций ВК. Текст доступен при hover/focus и на touch. Доставка по схеме SF: worker → публичный безопасный JSON/локальные фото → сайт. Используется официальный публичный виджет, ключ не нужен. Последняя успешная копия сохраняется при ошибке. Индикатор поцентру, без тиснения; бежевый градиент, незаметные кнопки покраям. Worker выбирает большую доступную версию фото вместо640pxминиатюры. Workflow GitHub подготовлен локально; внешняя публикация не выполняется.
6. Сетка/радиусы/промежутки/движение — существующие единые токены design.json/design.ts, модуль4px иφ для крупных пропорций. Без новых зависимостей runtime.

Последнее уточнение:4сертификата располагаются в одной CSS grid строке без отдельного веера, наклонов/смещения каждой карты. Только группа сохраняет3D-отклик; выбранная карта увеличивается и получает передний z-уровень. У каждого About-слоя индивидуальная нижняя граница, поэтому равные ступени остаются видимыми при выходе. У первого пункта шапки левый радиус равен половине высоты48px, справа12px; не использовать999px только слева, так как CSS уменьшит и правые углы.

Навыки: Ponytail full для простого решения через имеющийся код; ui-ux-design-system для токенов; impeccable-typeset для шрифтов/переносов; animate для ограниченного композиционного движения; agent-browser и verification-before-completion для реальной проверки.
