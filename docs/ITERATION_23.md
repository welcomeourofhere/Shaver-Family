# Шапка и подвал — 05.11.2026

Реализован последний запрос владельца: упругое появление/скрытие шапки, раскрытие «Ещё»/телефона наведением, полная пересборка подвала.

Шапка

- Нативная прокрутка, transform/opacity без изменения потока. Порог скрытия32px вниз после180px, возврата16px вверх. Возврат360ms на window-ветви общего осциллятора, скрытие240ms на спокойной popover-ветви, прозрачность180ms. Все значения и кривые — design.json/design.ts/spring.ts, новых зависимостей нет.
- При развороте направления CSS-прерывание продолжается из текущей позы. Дрожание направления от малых движений не переключает состояние. Фокус клавиатуры, меню и dialog удерживают шапку.
- Fine-pointer hover раскрывает меню сразу; уход закрывает через160ms, возврат отменяет закрытие. Панель удерживает открытие при нахождении мыши внутри. Один выбранный popover, закрытие снаружи/Escape, фокус возвращается на summary без повторного открытия. Touch/Enter/Space сохраняют управление нажатием. Фокус видимой клавиатурой открывает панель. При исчезновении верхней шапки меню закрывается.
- Transform origin рассчитан по неанимированной геометрии кнопки/панели, поэтому scale не сдвигает origin при прерывании. В невысоком окне панель ограничена доступной высотой и прокручивается. Reduced motion выключает движение.
