# Проход 34 — мобильные сценарии и аудит правил

07.11.2026. Локальная версия, `published: false`.

Продолжена мобильная переработка прохода 33. Добавлена независимая проверка пользовательских сценариев и аудит навыков/инструкций по отдельной просьбе владельца.

## Исправления продукта

- На планшете одновременно видны несколько карточек мастеров. Ранее при равной видимости нижняя панель могла сохранять предыдущего мастера после выбора соседнего. Теперь касание, нажатие, фокус и клавиатурные стрелки выбирают ту же карточку, которую читает панель. В кнопке записи видно имя выбранного мастера.
- Ленты мастеров и подарков получили общий счётчик, индикатор положения и стрелки. Нативная прокрутка сохранена. Ручное движение прерывает переход, края отключают соответствующую стрелку, reduced motion и клавиатура используют мгновенный переход. Когда все подарки помещаются, управление лентой скрыто.
- Меню на 320 px использует две колонки по доступной ширине и перестраивается по реальным размерам текста. Удалены повторяющиеся стрелки каждого пункта. Поля кнопок и области нажатия сохранены.
- Hero учитывает фактическую высоту заголовка, подписи, новостей и нижней панели. При обычном тексте фото занимает первый экран. При увеличении текста поверхность растёт и сохраняет доступ к содержимому. Панель новостей переносит элементы управления и ограничивает собственную прокрутку размером окна.
- Для мобильных действий статьи, акций, меню, подвала и настроек применены короткие подписи с полными доступными именами. Короткие темы FAQ хранятся рядом с исходными вопросами в `content/faq.json`. Обычные заголовки, названия услуг и контактный текст могут переноситься.
- Кнопка «Оставить отзыв» в акции «Кофе с собой за отзыв» теперь открывает общий выбор площадки. Тот же маршрут используют раздел отзывов и контекстная панель. Регрессионный тест сначала воспроизвёл неправильный `contact`-маршрут, затем подтвердил `review`.
- Safe-area задан четырьмя общими токенами в `design.json`. Hero, нижняя панель, категории, локальные окна и закрытие записи учитывают системные вырезы. Нижние окна сохраняют место сверху, обычные диалоги вписываются в безопасную область.
- Hover-состояния основных действий отделены от клавиатурного фокуса и ограничены возможностями указателя. Переключатель темы использует 16 px при coarse pointer, цвет браузерной панели следует выбранной теме.
- Из нижней панели убраны измерения ширины и запись размеров на каждом scroll. Геометрия обновляется по ResizeObserver, состояние раздела — через общий обработчик прокрутки. ARIA-связи определяются фактическим действием, статья сохраняет личный контекст до подвала.
- Локальный dev server получал `EBUSY` при наблюдении за файлами большого каталога `games`. Этот каталог исключён из watcher сайта, сервер перезапущен. Игровые материалы не изменялись.
