# Проход40 — ширина глобальной мобильной панели

07.11.2026. Прямое уточнение владельца: нижнее глобальное меню должно быть по ширине сайта.

CSS панели теперь использует ту же формулу, что `.shell`: `min(var(--content-max),calc(100% - var(--page-gutter) * 2))`. Убраны ограничение520px и вычисление внешней ширины из подписей. CSS владеет шириной; dock-surface.ts измеряет доступное место внутри toolbar и распределяет кнопки. Текстовые действия растягиваются, меню и стрелки сохраняют фиксированные размеры. Если подписи не помещаются, меняются строки. Safe-area защищает внутренние элементы, не сужая внешнюю оболочку относительно контента. Внизу сохраняется safe-area и прежний отступ.

Одно правило работает с1/2/3действиями и раскрытым меню. Анимации смены действий, раскрытия, прерывания и закрытия жестом сохранены. Другие диалоги сохраняют собственные ограничения ширины. ПК-стили не менялись; панель скрыта от961px.

Проверки на неизменяемом production build:

- 31 сценарий layout: 12 размеров × 2 темы, 4 меню и 3 варианта 200% текста. Проверка сравнивает фактические края панели с `.visit-section`, включая контексты с 1/2/3 действиями.
- 25 сценариев маршрутов/контрастов/настроек/safe-area/мыши. В safe-area проверяются внешнее совпадение с shell и защищённые внутренние контролы.
- 4 сценария движения панели: раскрытие/сворачивание, прерывание, закрытие жестом, отсутствие ошибок.
- Node 75/75, Astro 66 файлов — 0 errors / 0 warnings / 0 hints, build 2 страницы.

`tests/iteration40-production.py`: все3набора exit0, SHA256 всех267файлов сборки до/после совпали. Отчёт — `tmp/planning/iteration40-verification.json`, данные — `iteration40-layout.json`, `iteration40-journeys.json`, `iteration40-motion.json`.
