# Проход51 — десять вариантов карты и контактов

09.11.2026. Отдельная локальная галерея для выбора владельцем. В основной сайт вариант не переносился; published:false.

## Что подготовлено

Десять самостоятельных композиций с одной фактической основой, а не десять цветовых настроек прежнего блока:

| Номер | Вариант | Построение |
| --- | --- | --- |
| 01 | Адрес | Красная адресная табличка, крупный номер дома, карта справа, контактная полоса снизу. |
| 02 | Панорама | Карта занимает весь фон; адресный лист и управляющая расположены поверх. На планшете карта освобождается от наложений. |
| 03 | Билет | Синий билет с вертикальным корешком, перфорацией и отдельной контактной строкой. |
| 04 | Люди | Портрет и личная связь с управляющей становятся основной частью, сведения о визите и карта расположены рядом. |
| 05 | Диспетчерская | Графитовый пульт с переключением между барбершопом и управляющей. |
| 06 | Разворот | Журнальная композиция: крупная типографика, карта-открытка, подпись управляющей. |
| 07 | Три шага | Переключаемые сценарии записи, адреса и связи; карта остаётся общей. |
| 08 | Указатель | Красный городской указатель и круглая карта. При включении управления карта становится скруглённым прямоугольником без изменения габаритов. |
| 09 | Встреча | Расписание, широкая панорамная карта и две контактные полосы. |
| 10 | Перекрёсток | Центральная карта с четырьмя направлениями вокруг: телефон, адрес, сообщения, управляющая. |

Интерактивная страница: `/previews/contacts/`. Обзор и пары ПК/телефон: `/previews/contacts/overview/`. Выбор сохраняется в `#contact-01`…`#contact-10`. Есть стрелки, клавиатура, режимы ширины и ползунок280–1160px. Основные телефонные заголовки центрированы; кнопки не переносятся и сохраняют поля/область нажатия.

## Данные и общие владельцы

- Адрес, телефон, часы, ссылки записи и мессенджеров читаются из существующего `site.json`; управляющая — из `contacts.json`. Новых сотрудников/телефонов/условий нет.
- Подтверждённая точка организации49.669973,58.588674 прочитана из публичного виджета Яндекса, организация116019915414. Источник зафиксирован в `src/content/contact-map.ts`.
- В галерее используется открытая карта OpenStreetMap с этой точкой, без большой карточки организации поверх. Атрибуция сохраняется; у круглой карты продублирована отдельной доступной ссылкой. Маршрут ведёт в Яндекс по действующему запросу адреса. Карта главной не менялась.
- Разметка вариантов — `ContactConcept.astro`; небольшие атомы карты, фактов, действий и управляющей общие. У каждого варианта собственная композиция.
- Одновременно существует один загруженный iframe карты. У скрытых вариантов остаётся только template; старый iframe удаляется. Карта изначально не захватывает прокрутку; «Двигать карту»/«Готово» включает и выключает взаимодействие. При смене варианта блокировка восстанавливается.
- Запись использует существующий BookingDrawer и проверенный переход компании2763199 на встраиваемый хост. Реальная запись не создавалась. Общий loader «Сборка» используется без изменения геометрии/скорости.
- Переключение варианта использует общие токены времени/кривой, одновременно opacity и translate8px, с отменой предыдущей анимации. Reduced motion отключает её; клавиатурное переключение мгновенное. Круглая карта отключает деформацию при reduced motion.

- Node80/80; Astro91файл,0ошибок/предупреждений/подсказок; build5страниц.
- `python -X utf8 tests/iteration51-production.py`: две браузерные команды на неизменяемом локальном dist. SHA256 дерева до/после совпадает.
- Галерея:23проверки, включая60композиций на320/390/600/768/960/1160px и80сочетаний вариантов с200%текста, четырьмя viewport и двумя темами. - Обычная анимация сэмплируется в реальном браузере после запуска; проверено прерывание серией переключений. У круга размеры до/после включения карты равны, радиус меняется50%→24px. Это функциональное наблюдение, не измерение FPS.
- Проверены340текстовых/кнопочных ролей по вычисленным цветам в двух темах. Убраны недостаточно контрастные полупрозрачные контактные кнопки.
-36элементов главной: размеры и вычисленные стили совпали с baseline51 на1024/1440/1920px. SHA256 шести исходников главной/данных/токенов совпали с сохранённым началом прохода.
-20снимков получены из настоящего браузера с загруженными картами: ПК1160px и телефон390px. Источники/размеры/SHA256 — `public/previews/contact-concepts/manifest.json`. Снимок общего обзора — `artifacts/iteration51/contacts-board.jpg`.
- Страница сравнения проверяет30image-элементов,20уникальных файлов,10пар и10ссылок на варианты; ошибок страницы не найдено.

Манифест/логи — `tmp/planning/iteration51/verification.json`, `contacts.json`, `desktop.json`, `assets.json`. Снимки обновляются командой `python -X utf8 tests/iteration51-production.py --captures`, после неё нужна повторная сборка для статических файлов и размеров на странице сравнения.
