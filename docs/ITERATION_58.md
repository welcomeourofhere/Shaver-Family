# Проход 58 — отдельные правки адаптива

Дата: 10.11.2026. Работа локальная, published:false.

## Реализовано

- Существующие плакаты из `artifacts/service-posters-2026-11-10` подключены к активным услугам по service ID. Исходная фотографическая карта сохранена в `content/service-photos-photography.json`; оригинальные фото не удалены. Изображения заполняют вертикальную ПК-рамку, без квадратной вставки и пустого низа. В компактной версии прежняя маленькая полоса фото не возвращалась.
- Новая генерация остановлена по прямому указанию владельца. Последние сгенерированные изображения не подключены. Для услуги «Честная цена» использована существующая иллюстрация мужской стрижки без денег. Новое направление плакатов визуально не принято и не объявляется завершённым.
- В мобильном About раскрытый текст сохраняет прокрутку без вспышки scrollbar. В раскрытых отзывах — тонкая полоса, 3 px WebKit/thin Firefox, без кнопок прокрутки.
- Вопросы интервью — Manrope 600, обычный текстовый цвет в обеих темах. Заголовки глав и чередование линий ответов сохранены.
- Оба направления свайпа услуг выбирают следующую карту на ширинах до 960 px. Карта уходит в конец стопки; планшетная пересборка больше не возвращает предыдущую категорию.
- Компактный Hero использует бежевый вариант того же логотипа и увеличенный верхний отступ. Десктопный логотип сохранён.
- Средняя сетка отзывов от 800 до 1100 px доступной ширины — три колонки. Семь отзывов закрывают прямоугольник из пяти рядов без заполнителей: один узкий длинный модуль 1×3, вертикальные 1×2 и горизонтальные 2×1. Короткие отзывы вертикальны; все четыре цвета присутствуют, соседние цвета различаются. Широкий большой модуль остаётся в четырёхколоночном режиме. CSS до запуска JS соответствует новым планам.
