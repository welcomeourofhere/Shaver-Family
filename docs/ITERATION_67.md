## Проверка и выпуск

Сначала Astro и private build с полным Node-набором, затем чистая production-сборка и экспорт. Производные медиа включаются в новый media-lock. Для браузерной приёмки создаётся отдельная неизменяемая native-оболочка; задания выполняются последовательно. После подтверждения Cloud и source/CI публикуется тот же пакет, затем повторяются проверки настоящего HTTPS.

Подробные свидетельства: `COOKIE_DOCK_67.md`, `GESTURES_PLATFORM_67.md`, `DEVICE_SWITCH_67.md`, `FEEDBACK_67.md`, `CONTACT_MAP_67.md`, `PERFORMANCE_PLAN_67.md`. HMR-проходы не заменяют compiled/public результаты. Физические телефоны исключены владельцем; реальные записи, оплаты и сообщения не создаются. Продакшен Shaver Family не меняется.
