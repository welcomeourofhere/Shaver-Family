# Уточнение главной: восемь правок

Локальная работа, без публикации и действий с реальными записями. Последние требования пользователя имеют приоритет над предыдущими вариантами сетки.

1. Подарки: три столбца × два ряда, квадратные поверхности, шесть разных оттенков фирменной палитры. Иконка занимает 1/φ стороны карточки. Сертификат справа на ПК, нижний край по последнему квадрату без подписи.
2. Сертификат: заголовок → интерактивные карты → короткое описание → широкая кнопка. Размер карт зависит от фактической высоты сцены, а не прежней высокой карточки.
3. Мастера: отдельные таблицы цветов для 3×2 и 2×3. Для каждой позиции проверяются четыре ортогональных соседа; hover отличается и от собственной поверхности. В фокусе используется видимый клавиатурный фокус, а не остающееся после щелчка focus-within.
4. Кешбэк: явный перенос «на карту»; вращение лучей и привязка их центра к голове сохраняются.
5. Фото: единая нижняя строка сегментных индикаторов и компактных стрелок. Последнее уточнение: без стрелок/start-pause, автосмена6секунд и компактная стеклянная панель у нижнего края. Точки одновременно сужаются/расширяются, соседи сдвигаются одной анимацией Grid с неизменной суммой ширин. Переходы состояния используют существующий motion-ui; reduced motion сохраняется.
6. Верхний отступ hero: десять базовых модулей вместо семи. На телефоне без верхней шапки — четыре модуля.
7. Размеры: исходная единица 4 px; отступы и скругления — кратные модулю, оптические/типографические размеры — дробные шаги. φ применяется к соотношению колонок подарков/сертификата и размеру иконки. Производные CSS-переменные формируются в одном модуле; компоненты не задают собственные абсолютные размеры.
8. Проверка: Astro check/build, тесты источников и цветовых соседств, браузерные проверки ширин 320–1920, реального hover, карусели, сертификатов, квадратов, переполнений и однострочных подписей кнопок.

Навыки: Ponytail — существующие компоненты и зависимости; ui-ux-design-system — единая размерная шкала и роли цветов; animate — короткие обратимые переходы; agent-browser и verification-before-completion — проверка результата перед завершением.

Принято владельцем: индикатор60×22px, поля8px, промежутки6px, отступ справа/снизу12px. Без стрелок, start/pause и press-scale. Анимируется один список колонок Grid: (20,6,6)→(6,20,6)→(6,6,20), сумма32px постоянна. Внешние края всего ряда и подложка неподвижны, в том числе при прерывании/скачке через слайд. Старые FLIP и clip-path реализации удалены. Проверка — tests/hero-bounds-browser.py / tmp/planning/hero-bounds-qa.json.

Стандартизация: общие action/icon роли управляют состояниями мастеров без перекрывающихся background/color правил. Удалены скрытый header-burger и мобильная подпись desktop-кнопки, дубли reduced motion/полей/hover-теней. Неиспользуемые42токена и34размера удалены;6адаптивных значений, совпадавших с действующим каскадом, удалены. Динамические переменные проверяются по реальной SSR-разметке, поэтому подсветки услуг сохранены. Повторные проверки выполняются после изменений, без параллельной правки источников.
