# Публичная доставка СОЮЗа — границы проверки

Состояние на 16 ноября 2026 года, 02:09–02:20 МСК. Проверка доступности домена не подтверждает публикацию конкретной версии сайта.

## Подтверждённые факты

- Основной агент проверил UI Тильды: домен подключён корректно, назначенный IP — 176.57.67.208, SSL выпущен, защита от DDoS включена, DNS управляется Тильдой. Значения совпадают с независимыми DNS-проверками.
- Google Public DNS, Cloudflare DNS и прямые запросы к ns1.tildadns.com/ns2.tildadns.com возвращают один A — 176.57.67.208. www является CNAME основного домена. AAAA и CAA отсутствуют. RIPE RDAP относит адрес к Tilda_Publishing.
- MCP проекта 46815509 возвращает HTTPS=on, редиректы HTTP→HTTPS и www→основной домен. Ручной robots включён, nosearch пуст. Полного запрета индексации в сохранённых настройках нет.
- В 02:20 МСК основной агент выполнил независимую «Проверку ответа сервера» Яндекс Вебмастера для https://soyuz.hair/robots.txt. Получен HTTP 200 за 85 мс, server=ddos-guard, x-tilda-server=33. Основной агент открыл ответ и подтвердил совпадение с девятью строками сохранённого robots:

```text
User-agent: *
Allow: /
Disallow: /previews/
Disallow: /404
Disallow: /not-found
Disallow: /soyuz-header
Disallow: /soyuz-footer

Sitemap: https://soyuz.hair/sitemap.xml
```

- Из рабочей сети основной домен, www, robots и sitemap в 02:12–02:16 МСК не дали HTTPS-ответа: TLS handshake завершался тайм-аутом. Порт 80 также не ответил в пределах 8 секунд. В контрольном повторе технический домен stay-tan-habanero.tilda.ws и shaverfamily.ru дали HTTPS 200 и успешный TLS 1.3. Это ограничивает проблему маршрутом/входом к публичному адресу СОЮЗа, но не определяет её точную сетевую причину.

## Что из этого следует

Общий отказ домена **не доказан**: TLS и robots доступны из сети Яндекса. Недоступность из рабочей сети не следует выдавать за поломку приложения, неправильный DNS, истёкший сертификат или запрет в действующем robots. Ответ Яндекса подтверждает только проверенный robots и соединение с доменом; HTTP 200 главной страницы и доставка кандидата прохода 65 этим запросом не подтверждены.

Google Live Inspection в 02:04 МСК показал blocked robots. Это расходится с фактическим ответом robots для Яндекса в 02:20. Сохранённая прежняя версия robots времён nosearch — возможное объяснение, **гипотеза**, а не установленная причина. Следующий шаг основного агента — штатный запрос обновления robots в Google Search Console; факт отправки, результат запроса и последующую проверку нужно фиксировать отдельно. Индексация сайта не объявлена завершённой.

DNS, HTTPS, сертификат и DDoS-защита при этой диагностике не менялись и не отключались. Проверка через альтернативную сеть здесь не выполнена; обход сетевых ограничений и TLS-проверки не применялся. Снимки кабинетов, cookie, учётные данные и посторонние IP в документ не включены.

Публичные источники: [Google DNS](https://dns.google/resolve?name=soyuz.hair&type=A), [Cloudflare DNS](https://cloudflare-dns.com/dns-query?name=soyuz.hair&type=A), [RIPE RDAP](https://rdap.db.ripe.net/ip/176.57.67.208). По инструкции [Тильды](https://help-ru.tilda.cc/customdomain) адрес проверяется по назначению в настройках конкретного проекта; переносить IP другого сайта по аналогии нельзя.
