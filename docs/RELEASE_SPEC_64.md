## Неизменяемые ограничения

1. Продакшен Shaver Family19258126 и его файлы/аналитику не менять. Образец используется только для чтения архитектуры.
2. Физические телефоны исключены владельцем; эмуляция и Windows WebKit не называются проверкой физического Safari.
3. Никаких реальных записей, покупок, отправок обращений или сообщений другим людям.
4. Исходные медиа, фактические условия, авторские отзывы/интервью, идентификаторы и личные ссылки сохраняются.
5. Подпись кнопки — одна строка, без многоточия/обрезки, минимум12px по бокам и44px область нажатия. При нехватке ширины менять компоновку.
6. Новые данные и состояния не исправляют после загрузки заведомо неправильную начальную компоновку. CSS резервирует геометрию; неизбежные измерения не создают обратную связь с анимацией.
7. Исходная «Сборка» №04 остаётся единым loader:1250ms, задержки0/80/160/240ms, ease-in-out, радиус2px, прозрачность.3→1, выдержка44–65%. Reduced motion даёт спокойное состояние; невидимая анимация остановлена.
8. Нет розовых заголовков: светлая тема — красный, тёмная — фирменный жёлтый. Действующие ограничения Честной цены, интервью, компактных лент, Hero и контактов из DESIGN_SYSTEM сохраняются.
9. Секреты не попадают в чат, исходники, логи и публичные артефакты. Уже выданные разрешения не расширяются ради удобства автоматизации.

## Обязательный результат

### Взаимодействия

- Pending Hero показывает только общий loader; ссылка «Открыть ВК» под ним отсутствует. При успехе посты приходят через JSON после открытия, при ошибке есть понятное состояние и повтор, фокус не теряется.
- В normal motion фактически меняются кадры loader на Hero, фото и записи; reduced motion проверяется отдельно. Проверяются задержанные скрипты, медиа, сеть, скрытая вкладка, повтор и возврат к видимой области.
- Меню, «Ещё», часы, телефон, логотип, переходы по разделам и возврат из статьи работают мышью и клавиатурой. Шапка не обрезана, всплывающие части не оказываются под контентом.
- About: заголовок не закрывает текст карточек; все4карточки читаются при коротком/высоком окне и200%текста. Закрепление применяется только там, где обеспечивает читаемость. Полный проход вниз и обратно обязателен.
- Услуги, акции и компактные ленты проходят полный цикл, drag/release/cancel/interrupt и клавиатуру; верхнее меню не перехватывает жесты контента.

### Общие части Тильды

- Шапка и подвал — две отдельные нативные страницы с T123 из единых Astro-компонентов; назначены `headerpageid`/`footerpageid` в46815509.
- На главной,6интервью, юридических страницах и404 ровно по одной шапке, одному подвалу, одному общему dialog/menu/booking и одному владельцу состояния.
- Страницы общего оформления не входят в sitemap и не индексируются. В содержательных T123 нет скопированных header/footer. Структура готова при первом HTML, без перемещения разделов JavaScript после загрузки.
- Из общей шапки корректно работают локальный якорь на главной и `/#section` с внутренних страниц. Открытая страница не перегружается ради перехода внутри неё.

### Три документа

- Отдельные маршруты `/oferta`, `/privacy-policy`, `/privacy-data`, ссылки в общем подвале, читаемая печать/скачивание по образцу Shaver Family.
- Оператор и исполнитель, адрес, ИНН/ОГРНИП или ОГРН, контакты для обращений, продавец сертификата и применимые условия подтверждены источниками СОЮЗа/владельцем. Реквизиты Shaver Family не переносятся автоматически.
- Политика описывает фактический сайт, запись Yclients и аналитику. Просмотр согласия не считается его предоставлением. Оферта не обещает неподтверждённые сроки/ограничения возврата и не ухудшает права потребителя.
- В публикацию идут только заполненные проверенные документы; неподтверждённый проект сохраняется локально и не маскируется под действующие условия.

### Доставка, аналитика и поиск

- GitHub хранит воспроизводимые исходники/lockfile/проверки и отдельный путь СОЮЗа; workflow не может публиковать в SF. Секреты используются существующими защищёнными механизмами, значения не читаются.
- Облако: адаптивные изображения, исходные оригиналы сохранены, MIME/encoding/CORS/cache и хеши проверены. Изменённые ресурсы получают новый неизменяемый префикс; старые версии не удаляются из-под кеша.
- Валидный HTTPS на soyuz.hair, выбранный canonical, перенаправления и настоящий404. Сначала публичная приёмка, затем открытие robots/sitemap.
- Отдельные счётчики без дублей, корректные события открытия/контактов без персональных payload и выдуманной выручки. Получение публичного события подтверждается сетью/отчётом там, где сервис предоставляет доступ.
- Google Search Console и Яндекс Вебмастер: подтверждение, sitemap, проверка доступности; не обещать сроки появления в поиске.

## Условие завершения

В плане нет незакрытых обязательных дефектов; все изменения опубликованы и проверены по фактическому HTTPS; документация отражает результат/ограничения. Если внешняя задержка мешает части приёмки, цель остаётся активной, независимая работа продолжается, состояние не называется релизом.
