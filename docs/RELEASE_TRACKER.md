MIMEv4 не переиспользует старый immutable URL ради исправления metadata. Экспортёр явно задаёт `image/webp`, `image/jpeg`, `image/avif`, `font/woff2`, `font/woff`, `font/ttf` и остальные типы независимо от реестраWindows. MIME входит в build digest и в бинарную identity `SHA256(MIME + NUL + source bytes)`. Поэтому исправленное представление получает новый URL; старые объекты и оригиналы не перезаписываются.
