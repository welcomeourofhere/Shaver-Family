## Поведение

| Действие | Результат |
| --- | --- |
| Наведение мыши или фокус на карточке | Мягко увеличивается только портрет; цвет карточки меняется между ролями четырёх брендовых цветов. Наклона нет. |
| Фото, имя или маленькая круглая стрелка | Открывается диалог конкретного мастера через общий `motion.openDialog`. Это три отдельных элемента, без вложенных кнопок. |
| Escape, закрытие или нажатие за границами диалога | Общий `template.ts` вызывает `motion.closeDialog`; нативный диалог возвращает фокус инициатору. |
| «Записаться» в карточке или диалоге | Передаются `data-booking`, `data-master`, `data-context` в общую панель записи. Самостоятельного внешнего бронирования нет. |
| `prefers-reduced-motion: reduce` | Увеличение фото отключается; общий motion-слой открывает и закрывает диалоги без анимации. |

Все размерные и временные значения в `team.css` берутся из токенов.
