CorelDRAW создаёт отдельные растровые слои мягких внешних теней; они исключены ради требования полностью векторных SVG. Сами векторные тела предметов не перерисованы. Каждый файл имеет собственный плотный `viewBox` с небольшим полем 2 единицы, прозрачный фон и локальные определения градиентов. Метаданные происхождения, исходные ID групп, SHA-256 нативного экспорта и каждого результата, размеры и счётчики элементов находятся в `content/gift-vector-sources.json`.

## Как воспроизвести

1. Создать рабочую копию указанного CDR в `tmp/vector-export-tools/icons-source.cdr`. Библиотечный оригинал не открывать для записи.
2. Открыть копию в установленном CorelDRAW. Экспортировать в `tmp/vector-export-tools/native-icons.svg`: SVG 1.1, Unicode UTF-8, внутренний лист стилей, текст как кривые. Внешние ссылки/JavaScript не включать. После экспорта закрыть рабочие документы без сохранения CDR.
3. Выполнить `python scripts/vector-export-gifts.py`. Скрипт проверяет SHA-256 исходного CDR, извлекает только выбранные группы, сохраняет исходные векторные заливки/градиенты и локальные зависимости, исключает растровые тени и измеряет прозрачные границы через установленный в проекте `sharp`. Геометрия не трассируется.
4. Проверить `content/gift-vector-sources.json` и шесть SVG. Скрипт автоматически запрещает `image`, `script`, `foreignObject`, обработчики событий, data URL и внешние ссылки; проверяет локальные ссылки, уникальные ID, наличие path и viewBox.

Промежуточный нативный экспорт сохранён в `tmp/vector-export-tools/native-icons.svg` (около 1,95 МБ). PNG-превью каждого вектора и общий контактный лист `tmp/vector-export-gifts/contact-sheet.png` предназначены только для проверки; они не используются вместо SVG на странице.

## Проверки и исследования

- Визуально проверены все шесть предметов по контактному листу, отрендеренному `sharp`/librsvg. Они соответствуют исходному широкому набору и смыслу подписей, включая настоящий магнит и брелок вместо прежних placeholder серпа и флакона.
- Проверены SHA-256 оригинала и результатов, прозрачный фон, наличие векторных фигур и градиентов, отсутствие встроенных изображений и внешних ресурсов.
- Повторный запуск должен давать идентичные SVG и manifest; браузерную проверку интегрированного блока выполняет общий проход QA.
- Исследовательский portable `libcdr` из официальных пакетов [MSYS2](https://packages.msys2.org/packages/mingw-w64-ucrt-x86_64-libcdr) запускался через `cdr2xhtml`. Проверенные SHA-256 пакетов сохранены в `tmp/vector-export-tools/packages.json`; загрузчик `scripts/vector-export-tools.py` не устанавливает пакеты в систему. Экспорт большого макета сайта через эту библиотеку потерял заливки и был отклонён. Итоговые шесть SVG происходят исключительно из нативного экспорта CorelDRAW набора иконок.
- PyMuPDF в этой среде отображает часть SVG-градиентов Corel чёрными. Для визуальной проверки использовался корректный рендер `sharp`/librsvg; геометрия и градиенты не заменялись ради ограничения другого просмотрщика.

Оригинальная библиотека не изменена. Публикация, аккаунты, CRM и реальные заявки в экспорт не входили.
