# Верхняя шапка и увеличение текста — проход65

Проверяется именно увеличение размера текста до200% при прежнем viewport, а не масштабирование страницы. Исходный дефект подтверждён на1024×720: четыре левых действия не помещались в левую колонку шапки и заходили в область телефона. Запрет переноса подписей сохраняется.

## Исправление

`src/styles/header.css`: обе существующие группы действий допускают перенос самих элементов на следующую строку. Три колонки шапки, центральный логотип, внешняя ширина, поля и размеры обычных кнопок сохранены. При стандартном тексте элементы остаются на прежних местах. При увеличении текста высота шапки определяется содержимым сразу средствами CSS; отдельного JS-переключателя режима, клонированной навигации и исправления компоновки после загрузки нет.

Всплывающие панели получают ширину по содержимому с прежним минимальным размером и ограничением шириной окна. Увеличенная подпись «Контакты и карта» полностью помещается, без переноса или уменьшения боковых полей.

`src/scripts/header-menus.ts`: удалён избыточный флаг dismissed. При закрытии клавиатурой он запрещал следующее настоящее наведение, пока пользователь ещё раз не уведёт и не вернёт мышь. ВFirefox дефект также проявлялся, когда меню раскрывалось под неподвижной мышью, а его скрытие не отправляло pointerleave. Новое pointerenter открывает меню; восстановленный послеEscape фокус защищён прежним restoringFocus. Состояние остаётся у прежнего владельца details, новых состояний не добавлено.

## Три верхних окна

По последнему уточнению владельца часы вHeader используют тот же header-menus/details и MaterialSurface, что«Ещё» и телефон. В этой области нет второго InfoTip. Нижние часы сохраняют прежний общий InfoTip. BusinessHoursStatus.astro задаёт одну разметку статуса для обоих мест, расчётbusiness-clock не менялся.

Все три верхние панели привязаны к нижней границе капсулы с отступом8px, включая двухстрочную шапку при200% текста. Фон, радиус20px и материал общие. Горизонтальное положение определяет тот же владелец при открытии и изменении размеров, с ограничением краями капсулы. Измерение учитывает существующий floating-scale, не создавая нового состояния навигации.

Зазор8px покрывает общий прозрачный псевдоэлемент панели. Он не заходит на кнопки. Проверяется реальная задержка указателя в середине зазора350ms, дольше close-delay160ms, для каждого из трёх popup. Внутри выросшей шапки окно удерживает общий capsule:hover; переход от верхней строки к нижней не требует ускорять мышь.

ArrowDown наsummary открывает тот же popup и сразу переводит фокус на первую видимую ссылку. Escape возвращает фокус кsummary. Это единое поведение владельца, без смены tabindex ссылок. СтендWebKit по умолчанию пропускает ссылки поTab даже в чистомHTML details; это отдельно фиксируется native-контролем. Клавиатурный путь к ссылкам popup проверяется настоящими Tab иArrowDown во всех движках. Физические настройкиSafari этим не подтверждаются.

Часы показывают жирный статус, межтекстовую точку и обычный отсчёт в одной строке наПК. Ширина определяется содержимым, на узких размерах и200% текста допускается перенос смысловых частей. Слева сохранён отдельный цветной индикатор. Открыто — общий семантический status-open, последние120минут работы — yellow, закрыто — red. График11–22 и часовой поясEurope/Moscow остаются у прежних владельцев.

## Небольшая высота окна

Дополнительный проход выявил реальное обрезание при1024×480 и200% текста. Прежний max-height вычитал64px высоты шапки, а выросшая капсула занимала около150px. Нижняя граница меню находилась на544.7px при viewport480px.

Доступную высоту теперь определяет общий placePanel по фактической нижней границе капсулы, отступу8px и нижнему резерву16px. Величина задана через100dvh, поэтому уже открытое меню реагирует на изменение высоты окна без отдельного обработчика и нового состояния. Расчёт учитывает floating-scale. MaterialSurface сохраняет единственную внутреннюю прокрутку у правого края.

`tests/iteration65-menu-short-height.py` проверяет обе темы при200% текста на320×320,600×320,1024×480 и1440×600. Последний размер дополнительно сужается по высоте до480 при открытом меню. Проверяются границы окна, реальное колесо во внутреннем scrollport, достижимость последней ссылки, её полная подпись и переход клавишейEnter. На компактных размерах используется существующее нижнее меню, наПК — общий popupHeader.

## Проверка

`tests/iteration65-header-text-fit.py` проверяет961/1024/1280/1440×720, обе темы, обычный текст и200% текста. Увеличение повторяет метод общего визуального аудита: сначала фиксируется вычисленный размер каждого элемента с непосредственным текстом, затем каждый размер удваивается.

В каждом сочетании проверяются:

- отсутствие пересечений действий, положение центрального логотипа и расположение элементов внутри капсулы;
- одна строка подписи, отсутствие обрезки, минимум44px по высоте и12px с каждой стороны текстовой кнопки;
- настоящие наведения на«Ещё» и телефон, размеры открытых панелей, доступность ссылки звонка без выполнения звонка;
- последовательная клавиатурная навигация, ArrowDown к ссылкам обоих меню, закрытие поEscape и возврат фокуса;
- переход по настоящей ссылкеFAQ, фокус его заголовка и отсутствие перекрытия шапкой после завершения прокрутки;
- неизменная геометрия при обычном тексте в сравнении с прежним nowrap в том же загруженном DOM.

Отдельные сценарии проверяют reduced motion и задержку настоящего JS-модуля Header в статической сборке: размеры и положения при200% текста до и после его запуска одинаковы.

Перед этим после перезапуска4321 подтверждена доставка актуального CSS черезCSSOM.
