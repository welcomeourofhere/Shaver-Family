## Область и доказательства

Для каждого размера сохранены Hero, услуги, акции, мастера, Честная цена, О СОЮЗе, подарки/сертификаты, отзывы, FAQ, контакты и подвал. Полный раздел снимается нативным clip без изменения CSS viewport; окна пересняты обычным screenshot в свежих контекстах.

Индекс первого прохода — `tmp/planning/iteration65/visual-mobile.json` (222 изображения), свежие окна — `visual-mobile-fresh.json` (64), заключительные состояния — `visual-mobile-final.json` (18). Это число изображений, не число автоматических успешных сценариев. Изображения находятся в `artifacts/iteration65/visual-mobile/`. Просмотрены все типы разделов и окон в обеих темах, телефонная/планшетная/альбомная композиции и увеличенный текст. Просмотр исходных длинных section-снимков дополнен реальными viewport-снимками для находок.

Внешняя карта и iframe записи подменялись явно подписанными UTF-8 макетами для проверки оболочки. Лента использовала сохранённый JSON с CORS. Эти снимки не доказывают живую доставку карты, каталог поставщика, оплату или запись. Физические устройства не использовались.

## Заключительная проверка кнопок мастеров

`tests/iteration65-team-labels.py` выполнен в Chromium, Firefox и WebKit:120 комбинаций ширины/темы/масштаба,1440 проверок подписей записи и знакомства. Ширины320,390,600,768,960,961,1024,1100,1200,1440; обе темы; обычный и удвоенный текст. В каждой карточке проверены реальный текстовый Range, одна строка, размещение между боковыми полями, поля≥12px, область нажатия≥44px, отсутствие overflow и полное aria-label с именем. После изменения размера текста даётся500ms на завершение ResizeObserver/шрифтов; промежуточный кадр WebKit через120ms не выдан за окончательное состояние.

Все120 случаев прошли. Результаты — `tmp/planning/iteration65/team-labels-{chromium,firefox,webkit}.json`; кадры — `artifacts/iteration65/team-labels/`. По последнему уточнению владельца подпись заменена на «Знакомство», выровнена по центру фотографии; поля увеличены с12до20px при ширине по содержимому. У фото и плашки остался один кнопочный владелец/Tab stop. Dock и доступное имя согласованы. Во всех случаях центр отличается не более чем на.6px, плашка занимает менее90%фото. Дополнительно прошли72 сценария всех6мастеров на320/1440 в обеих темах: Tab→запись, Shift+Tab→фото, Enter→нужное окно, Escape и нажатие самой плашки. WebKit проверен на отдельной frozen private-сборке4366; непостоянные HMR focus/Enter во время параллельных правок не воспроизвелись в статике. Самостоятельно просмотрены320px/200% в обеих темах,1024/dark/200% и1440/light: обе подписи целиком, размер и поля сохранены. `astro check`:122 файла,0 ошибок/предупреждений/подсказок. `mobile-navigation`, `style-contract` и `team-colors`:8/8. `check-ci.mjs check`:35 runtime suites,7 local provenance suites,8 Python suites после явного включения нового business-hours65. Новые браузерные `iteration65-*.py` намеренно выполняются отдельно от unit CI.

## Отброшенные ложные сигналы

- Одинокая «Ы» в сертификатах первого320px снимка относилась к промежуточному8px gutter. На текущем4px ширина текста276px, заголовок занимает две обычные строки: `confirmed-certificate-320-light.png`.
- «К содержанию» на части полных section-capture — offscreen fixed skip-link, захваченный CDP вне viewport; на обычном viewport его нет.
- Пустые ранние окна после raw CDP capture не воспроизвелись в свежем Playwright-контексте. Эти кадры не используются для заключения о сайте.
- Ранний `interview-read` менял scrollTop у overflow:hidden `.surface-viewport`. Настоящий владелец прокрутки — `.surface-content`; свежие `final-*-interview-reading.png` показывают корректное содержимое.
- Кракозябры внутри раннего макета карты были ошибкой charset тестового fixture; это не данные сайта/Яндекса.
- Вызов кнопки графика до завершения автоматического scroll мог закрывать tooltip обработчиком scroll. После явного scroll/settle график открывается: `final-600x400-dark-hours.png`.

После перезапуска HMR с рабочим polling новые CSS действительно доходят в браузер. Исторические222/64 кадра не объявляются единым неизменным финальным build; свежие `final-*` подтверждают исправленные зависимые состояния. Этот документ не заменяет окончательный release build, cold bootstrap65, публичный smoke и общую приёмку root.
