# Публичные новости СОЮЗа

Изолированный поток для сообщества `-210007626`. Он использует `wall.get` официальногоVKAPI и выбирает самый крупный объявленный размер первой фотографии поста, включая посты с несколькими вложениями. ПодписанныйURL используется без изменения; WebP640/1280/1600 создаются без увеличения исходника.

В GitHub-репозитории `welcomeourofhere/Shaver-Family` worker и тесты размещаются только в `soyuz/`, workflow — `.github/workflows/soyuz-news.yml`. Основной поток Shaver Family и его данные не изменяются. Расписание СОЮЗа — ежедневно03:20UTC, также доступен ручной запуск.

Ключ находится только в Actions Secret `SOYUZ_VK_TOKEN`; при его отсутствии используется существующий `VK_TOKEN`. Значение передаётся только вPOST `https://api.vk.com/method/wall.get`, не попадает в JSON,URL, исходники или логи. Ключ должен разрешать чтение публичной стены через этот метод. Если серверный ключ SF подходит, отдельный ключ не нужен.

Публичный результат: `https://welcomeourofhere.github.io/Shaver-Family/soyuz/public/data/news.json`. Снимок записывается только после успешного чтения10постов и обработки фото; при отказе прежнийJSON остаётся. Это публикация новостного снимка, а не сайта СОЮЗа.

Локальная проверка: `python -m unittest discover -s tests -p 'vk_news*_test.py'`. Ручной сбор с ключом выполняется в серверной среде: `python scripts/update-vk-news.py --public-only`. Без ключа локальный worker сохраняет прежний публичныйwidget-путь; он не гарантирует оригинальное качество фотографий.
